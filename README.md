# Hello Constraint App 📱

Enostavna Android aplikacija, ustvarjena v sklopu šolskih vaj za spoznavanje gradnika **ConstraintLayout** ter osnovnega upravljanja z dogodki (Event Handling) v Android Studiu.

---

## 🚀 Funkcionalnosti aplikacije
* **Števec (Count):** Pritisk na gumb "Count" poveča trenutno vrednost števca na zaslonu za 1.
* **Prikaz obvestila (Toast):** Pritisk na gumb "Toast" prikaže kratko skočni obvestilo (Toast message) na dnu zaslonu.
* **Ponastavitev (Reset):** Možnost ponastavitve števca nazaj na vrednost `0`.
* **Sprememba barve:** Dinamična sprememba barve gumba ali ozadja glede na to, ali je število sodi/liho ali enako 0.

---

## 🛠️ Uporabljene tehnologije in gradniki
* **Razvojno okolje:** Android Studio
* **Programski jezik:** Java / Kotlin
* **Postavitev (Layout):** `ConstraintLayout`
* **Uporabljeni UI gradniki:**
  * `TextView` – za prikaz trenutnega števila (števca).
  * `Button` – gumbi za interakcijo (`Toast`, `Count`, `Zero/Reset`).
  * `Toast` – razred za prikaz kratkih sporočil.
